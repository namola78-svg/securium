# ISRM S04-U02 authoring draft

This directory is a review-only, unpublished authoring package for:

- course: `course-isrm`
- subject: `isrm-2025-2027-s04`
- learning unit: `isrm-2025-2027-s04-u02`
- questions: `isrm-q-v2-23`, `isrm-q-v2-24`

The official criteria anchors Subject IV, information-security management-system operation, and the broad information-security risk-assessment item. Its listed subitems include assessment-method selection/preparation and information-security risk assessment. It does not provide an official Securium U02 title or detailed objective set. The title and objectives in this package are Securium independent pedagogical content.

This unit continues S04-U01 by using its operating-plan boundary and review triggers to keep an assessment current. It teaches how to check purpose, scope, method, assessment inputs, target-risk comparison, evidence, and uncertainty when a service or risk context changes. It keeps assessment distinct from treatment selection, approval, and implementation.

The scenarios and questions are independently authored and fictional. Official local PDFs are used only for bounded factual/reference anchors. `sourceExpressionReuse` is `0`; commercial PDFs, official sample-question wording, and legacy unbound candidate wording were not used.

The package is not canonical content, an approval record, a revision binding, a publication input, or a runtime registration. Canonical approval, source-binding approval, permission for expression reuse, currentness beyond the available source evidence, runtime materialization, and publication remain unresolved or not requested.
