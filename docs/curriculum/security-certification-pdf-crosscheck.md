## 코드 반영 내용

확인된 사실:

- `lib/curriculum/security-certification-standards.ts`에 `examTracks` 메타데이터를 추가했다.
- Flatten된 `CurriculumNode` metadata에 `confirmedFromPdf: true`, `needsPdfVerification: false`, `pdfCrossCheckedAt: "2026-08-01"`을 반영했다.
- 필기·실기 TRACK 노드 metadata에는 시험 방식, 문항수, 시험시간, 원문 페이지 근거를 함께 저장한다.
- D1/PostgreSQL seed SQL은 같은 TypeScript 정의에서 재생성한다.

제안사항:

- PDF 페이지 번호를 UI 상세 패널에 표시할 때는 `metadata.examTrack.sourcePages`를 우선 사용한다.
- 세세항목 단위의 정확한 PDF 페이지가 필요해지면 OCR/수동 입력을 통해 노드별 `sourcePages`를 확장한다.
- 운영 DB 활성화는 별도 승인 후 `DRAFT` 트리 검수 → `ACTIVE` 전환 순서로 진행한다.
