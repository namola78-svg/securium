# Core Screen Review Checklist

This checklist is used during UI-2D review sessions.

## Review Session Format

For each screen:

1. Read the screen purpose.
2. Confirm the primary user question.
3. Check the first visual area.
4. Check the Primary CTA.
5. Review Empty, Loading, Error states.
6. Review mobile behavior.
7. Review accessibility notes.
8. Confirm reusable components.
9. Identify new component candidates.
10. Assign GO, CONDITIONAL GO, or NO-GO.

## Decision Labels

| Label | Meaning |
| --- | --- |
| GO | Ready for implementation mapping |
| CONDITIONAL GO | Ready if listed issues are handled |
| NO-GO | Needs redesign before implementation |
