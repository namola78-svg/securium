# Preview Beta Tester Guide

Welcome to the SECURIUM Preview Beta.

SECURIUM is an AI-assisted learning platform for information security and privacy protection professionals. This beta checks whether the learning flow is clear, trustworthy, and useful before a wider release.

## What to test

Please focus on these questions:

1. Do you understand what SECURIUM helps you do?
2. Can you find the right course?
3. Can you identify your next learning action?
4. Can you tell the difference between official curriculum, practice content, and AI-generated support?
5. Can you recover when a page has no data yet?

## Test environment

Use:

`https://securium.vercel.app`

Use only the test account provided by the facilitator. Do not enter private credentials, secret keys, real personal data, or paid textbook/exam content.

## Learner tasks

1. Open the home page.
2. Explain what SECURIUM is in your own words.
3. Open the course list.
4. Choose a course that fits your goal.
5. Open the course detail page and explain what the primary button will do.
6. Log in if needed.
7. Open the dashboard and identify the next recommended action.
8. Open the curriculum for 정보보안기사.
9. Find where to practice questions.
10. Open AI Tutor or an AI explanation area and explain whether it feels official or supplemental.
11. Open wrong notes or today's review.
12. Open analytics and explain what the current state means.

## Admin tasks

Admin testers should also check:

1. Open the admin dashboard.
2. Find Curriculum.
3. Find Coverage.
4. Find Ontology.
5. Find AI Explainability.
6. Find Content Revisions.
7. Find Question Reports.
8. Explain what the Inspector panel is showing.

## How to give feedback

For each issue, please record:

- Page or route.
- What you expected.
- What happened.
- Whether you could continue.
- A short quote or screenshot if helpful.

Do not include passwords, tokens, API keys, or private user data in feedback.

## Things we especially want to know

- Which labels felt too technical?
- Which screen felt most useful?
- Which screen felt unfinished?
- Did any AI explanation feel too confident?
- Did any page make you unsure what to do next?
- Did the mobile menu or account menu feel easy to use?

## Completion

The session is complete when you have finished the assigned learner or admin tasks and submitted the feedback form.
