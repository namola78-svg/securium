# Motion

SECURIUM의 전환, hover, loading, drawer, dialog motion 기준을 관리한다.

## 원칙

- 학습을 방해하지 않는 짧은 움직임만 사용한다.
- 상태 변화는 인지 가능해야 한다.
- 과도한 장식 motion은 사용하지 않는다.
- 추후 reduced-motion 대응을 기준에 포함한다.

## 우선 정의 대상

- Button hover/focus
- Card hover
- Drawer open/close
- Dialog open/close
- Loading skeleton
- Toast enter/exit
