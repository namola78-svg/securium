# Product Roadmap

SECURIUM의 로드맵은 기능 확장보다 제품 명확성을 먼저 안정화하는 방향으로 관리한다.

## Current Direction

1. Product Foundation
2. Component Library
3. Student Core Screens
4. Admin Core Console
5. AI Explainability
6. Ontology Console
7. Coverage Workflow
8. Motion and Accessibility refinement
