# Coverage

SECURIUM의 공식 커리큘럼 대비 콘텐츠·문제·온톨로지 연결 커버리지를 관리한다.

## 포함 범위

- CurriculumNode coverage
- CourseLesson coverage
- Question coverage
- Ontology coverage
- Gap Action Queue

## 원칙

- 누락을 발견하면 바로 액션으로 연결한다.
- 커버리지 상태는 과정별로 분리한다.
- 공식 출제기준 노드 기준으로 집계한다.
