# Learning

SECURIUM의 학습 경험, 과정 구조, 진도, 복습, 분석 기준을 관리한다.

## 포함 범위

- Course
- CourseLesson
- LessonProgress
- QuestionAttempt
- WrongNote
- Review
- Analytics

## 설계 원칙

- 과정별 진도는 완전히 분리한다.
- 공식 커리큘럼을 학습 경로의 중심에 둔다.
- 콘텐츠, 문제, 복습, AI 설명이 연결되어야 한다.
