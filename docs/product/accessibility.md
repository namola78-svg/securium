# Accessibility

SECURIUM 접근성 기준을 관리한다.

## 최소 기준

- 주요 버튼 44px 이상
- 명확한 focus-visible
- 아이콘 버튼 aria-label
- Dialog/Drawer ESC 닫기
- 로딩 role=status
- 오류 role=alert
- 색상만으로 상태 구분 금지
