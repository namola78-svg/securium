# SECURIUM Wireframes

이 폴더는 SECURIUM 핵심 화면의 텍스트 기반 와이어프레임을 관리한다.

Figma 파일을 만들기 전에도 Codex와 제품 설계를 같은 기준으로 공유할 수 있도록 화면 목적, 정보 우선순위, CTA, 빈 상태, 모바일 구조를 문서화한다.

## Wireframe Format

각 화면은 다음 구조를 따른다.

1. Purpose
2. Primary User Question
3. Layout
4. Key Components
5. Primary CTA
6. Empty State
7. Error State
8. Mobile Behavior
9. Accessibility Notes
