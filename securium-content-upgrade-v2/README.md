# SECURIUM Content Upgrade V2

이 패키지는 첨부된 정보보안기사 자료의 **이론 + 필기 + 실기 전체**를 SECURIUM에 반영하기 위한 전수 변환 작업용입니다. 원문을 복사해 넣는 패키지가 아니라, 첨부자료를 학습목표/개념/출제의도 참고자료로 사용하고 SECURIUM 고유 콘텐츠를 새로 만드는 것을 전제로 합니다.

## 확인된 원천 범위

- 이론: 핵심 용어 108선 → 인벤토리 108개
- 필기: 최신 기출 3회 × 100문항 → 인벤토리 300개
- PDF 실기: 3회 × 최대 18문항 → 인벤토리 54개
- 별도 실기 TXT: 단답형/서술형/실무형 구간을 추가 원천으로 사용

## 파일

- `data/source-inventory.json`: 전체 변환 대상 목록
- `data/theory-seeds.json`: SECURIUM식으로 새로 작성한 이론 샘플
- `data/written-seeds.json`: 원문을 복제하지 않은 필기 신규문제 샘플
- `data/practical-seeds.json`: 로그/코드/사례 중심 실기 신규문제 샘플
- `content-policy.ts`: 복제/단순 패러프레이즈 차단 정책
- `CODEX_TASK.md`: Codex가 전체 인벤토리를 끝까지 처리하도록 하는 작업지시서
- `scripts/validate.py`: 기본 데이터 검증

## 핵심 처리 방식

`원천자료 → 개념/학습목표/출제의도 추출 → SECURIUM 기존 콘텐츠 비교 → 이론 보강 → 새 문제 설계 → 중복검사 → DRAFT 등록 → 검수 → 게시`

필기 원문 문제의 보기 순서만 바꾸거나, 실기 문제에서 IP/숫자만 바꾸는 방식은 허용하지 않습니다. 새 문제는 같은 개념을 평가하되 **새로운 상황 또는 새로운 추론 경로**를 가져야 합니다.

## 실행 권장

이 폴더와 첨부 원천파일을 SECURIUM 저장소 내부의 작업 폴더에 넣은 뒤 Codex에 `CODEX_TASK.md`를 수행시키십시오. 먼저 현재 DB/schema와 콘텐츠 모델을 읽고 어댑터를 만든 뒤 DRAFT 상태로 넣도록 지시되어 있습니다.
