# Securium UX 전수 분석 및 개선 기록

## 1. Executive Summary

Securium은 Next.js App Router 기반의 정보보안 학습 플랫폼으로, 과정 탐색, 커리큘럼/레슨, 문제풀이, 오답·복습, 분석, 모의고사, 실무형 콘텐츠, AI 보조 기능과 관리자 운영 화면을 갖추고 있다. 이번 점검에서는 실제 공개 데이터 수를 기준으로 과정 상태를 표시하는 구조는 유지하면서, 공개 탐색 CTA와 검색 진입점을 보강했다.

현재 핵심 UX 위험은 기능 부재보다 런타임 경로가 여러 개이고 E2E 서버 기동이 불안정하며, 일부 공개 메시지가 실제 AI·추천 수준보다 앞서갈 수 있다는 점이다.

## 2. 발견 문제

### High
- E2E가 `vinext dev` readiness 단계에서 반복 timeout된다. 포트 충돌, localhost 주소 해석, Node 엔진 범위 문제는 확인되지 않았다.
- Next.js/Supabase·PostgreSQL와 Vinext/Cloudflare·D1 경로가 함께 존재해 운영 primary path를 별도 문서로 명확히 해야 한다.

### Medium
- 공개 과정 CTA 일부가 레거시 `button-*` 클래스와 공통 `ActionButton`을 혼용하고 있었다.
- 공개 검색 진입점인 `sitemap.xml`, `robots.txt`, 과정 상세 canonical이 부족했다.
- 랜딩은 AI 근거·복습 추천을 강하게 약속하므로 실제 provider 및 추천 수준과 문구를 지속적으로 대조해야 한다.

### Low
- 관리자/운영 화면은 학습자 화면보다 영문 inspector 용어가 많아 일반 학습자 경험과 분리된 운영 UI임을 명시할 필요가 있다.

## 3. UX 개선

- 과정 카드의 실제 과목·주제·문항 수를 계속 표시하고, 데이터가 없는 과정은 `개설 예정`과 `문항 업데이트 예정`으로 표현한다.
- 문제풀이 허브와 과정 카드의 CTA를 공통 `ActionButton`으로 통일했다.
- 문제풀이 세션의 진행률, 제출, 결과, AI 해설, 신고 문구를 한국어로 통일했다.
- 제출 결과/오류를 `aria-live`로 전달하고 신고 폼 입력에 명시적 label을 추가했다.
- 모바일 문제풀이 카드의 여백, toolbar wrapping, CTA 최소 touch target을 보강했다.
- 과정 상세 metadata canonical을 실제 slug 기준으로 추가했다.

## 4. UI 개선

- `components/course-card.tsx`, `app/practice/page.tsx`의 레거시 CTA를 공통 버튼 primitive로 교체했다.
- 기존 dashboard/nav CTA 용어 정리와 인증 패널 상태 처리 개선을 유지했다.

## 5. 학습 시스템

- 문제풀이, 오답, 복습, 추천, 과정별 진도 데이터 경로와 관련 라우트를 확인했다.
- rule-based 복습 우선순위와 과정 범위 격리는 구현되어 있다.
- 다음 우선 작업은 문제풀이 결과 화면에서 다음 행동, 오답 저장, 복습 진입을 하나의 명확한 종료 흐름으로 검증하는 것이다.

## 6. AI

- provider abstraction과 Mock/OpenAI 선택 구조가 존재한다.
- AI 설명과 전문 콘텐츠 검토 API가 구현되어 있으며, 단위 테스트는 Mock 외부 호출 차단과 근거 메타데이터를 검증한다.
- 학습자 개인 데이터 기반 adaptive recommendation이 완전한 LLM 기능으로 활성화됐다고 판단하지 않았으며, 현재 rule-based 추천을 실제 기능 기준으로 취급한다.

## 7. 콘텐츠

- 공개 과정은 DB 집계의 과목·주제·문항 수를 사용한다.
- 실제 콘텐츠가 없는 과정은 학습 가능으로 가장하지 않는다.
- 과정 상세에서도 실제 콘텐츠가 없는 과정의 등록 CTA를 숨기고 `개설 예정` 안내를 표시한다.
- 보안 자격증 공식 커리큘럼과 과정별 CourseLesson/공유 Content 분리 구조가 존재한다.

## 8. Architecture

- Active: Next.js App Router, React, 공통 DB repository/domain 계층.
- Runtime paths: Supabase/PostgreSQL와 Cloudflare D1/Vinext가 함께 존재한다.
- 운영 primary path와 rollback/실험 path를 별도 문서로 고정하는 작업이 남아 있다.

## 9. Performance

- dashboard는 Promise 병렬 조회와 Suspense를 사용한다.
- 공개 catalog는 cache wrapper를 사용한다.
- Vinext dev 초기화 지연은 성능/개발 경험 위험으로 별도 조사해야 한다.

## 10. Accessibility

- 주요 내비게이션 aria label과 활성 위치 title을 정리했다.
- mobile drawer focus/escape 흐름과 버튼 disabled/loading 상태가 구현되어 있다.
- 과정/문제풀이 CTA는 공통 버튼 primitive로 의미를 통일했다.

## 11. SEO

- `app/sitemap.ts` 추가: 공개 정적 경로와 공개 과정만 포함.
- `app/robots.ts` 추가: API/관리자/운영/인증 경로 차단.
- 과정 상세 canonical 추가.
- 과정 상세에 `Course`와 `BreadcrumbList` JSON-LD를 추가했다.
- 과정별 OpenGraph 확장은 다음 SEO 배치로 남아 있다.

## 12. Security

- 인증 return path 외부 URL 차단과 redirect query builder 계약을 단위 테스트로 검증했다.
- 관리자/API/RLS/입력 검증 관련 기존 테스트가 존재한다.
- 이번 배치에서는 production secret, 사용자 데이터, 원격 DB를 변경하지 않았다.

## 13. Database

- D1/PostgreSQL adapter, repository contract, course-scoped progress와 shared content 경계를 확인했다.
- 실제 운영 row count와 고아 데이터는 연결된 운영 DB 승인 없이는 검증하지 않았다.

## 14. Removed Legacy

- 이번 배치에서 공개 과정/문제풀이 CTA의 레거시 버튼 사용을 제거했다.
- 기존 레거시 CSS 전체 제거는 시각 regression 위험 때문에 보류했다.

## 15. Tests

- `npm run typecheck`: PASS
- `npm run lint`: PASS
- `npm run build`: PASS, 63개 route 생성
- `npm run test:unit`: PASS, 312/312
- `npm run test:e2e`: FAIL/timeout. `vinext dev` readiness 단계에서 서버가 준비되지 않음.

- `app/courses/[courseSlug]/page.tsx`: Course/BreadcrumbList JSON-LD 추가
